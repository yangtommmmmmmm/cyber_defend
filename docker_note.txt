1.Docker-Compose:                                                                                                                                                                                                  Docker-
This tool is for managing the different containers(each container for one service).      
Definition:[One service] determine [the specific image(read only file)] to setup the [container(use CPU)]

1-1.Docker-Compose.yml:
Reference:
https://docs.docker.com/compose/compose-file/
https://docs.docker.com/compose/compose-file/#compose-file-structure-and-examples

1-2.Basic Docker Command:
1-2-1.Check the current container:
docker-compose ps
--->Add '-q' to demonstrate only 'id'
-----------------------------------------------------------------------------------------------------------------------------
1-2-2.Only Service Related:
1-2-2-1.Start:docker-compose start [SERVICE]--->If no SERVICE,system will start all services
1-2-2-2.Stop:docker-compose stop [SERVICE]--->If no SERVICE,system will stop all services
1-2-2-3.Restart:docker-compose restart [SERVICE]--->If no SERVICE,system will restart all services. restart=stop+start
1-2-2-4.Remove:docker-compose rm [SERVICE]--->If no SERVICE,system will remove all services
1-2-2-5.Check the service log:docker-compose log [SERVICE]--->If no SERVICE,system will show all logs for all services
-----------------------------------------------------------------------------------------------------------------------------
1-2-3.All Settings Related:
1-2-3-1.docker-compose up:
Stop all containers--->Remove all containers--->Remove all Networks--->Read the docker-compose.yml again
--->Setup
*If u add '-d',this command will trigger in background.
*If u have many yaml files,such as docker-compose.yml,docker-compose-dev.yml,you can use -f(or --file) to specify one yaml file:
docker-compose -f ./docker-compose-dev.yml up -d
*If u would like to build images before starting containers:
docker-compose up -d --build

1-2-3-2.docker-compose down:
Stop all containers--->Remove all containers--->Remove all Networks--->Remove Volume,Image(Selected)
*If u would like to delete the volume:
docker-compose down -v
*If u would like to delete the image:
docker-compose down --rmi all
-------------------------------------------------------------------------------------------------------------------------------
1-2-4.Run the command in service:
docker-compose run/exec web bash--->Run the bash in web service
-------------------------------------------------------------------------------------------------------------------------------
1-2-5.Check the format of docker-compose.yaml file:
docker-compose config
-------------------------------------------------------------------------------------------------------------------------------
1-2-6.Show all images:
docker-compose images
-------------------------------------------------------------------------------------------------------------------------------
1-2-7.Push images to docker hub:
docker-compose push
-------------------------------------------------------------------------------------------------------------------------------
1-2-8.Specify the ports and expose to localhost:
1-2-8-1.To docker-compose.yml, add [ports] to service:
.....
ports:
  - "5000:5000" #let container-5000 port exposed to localhost-5000 port
  - "5001:5000" #let container-5000 port exposed to localhost-5001 port
  - "5000" #let container-5000 port exposed to localhost-all ports

1-2-8-2.To docker-compose.yml, add [expose] to service:
.....
expose:
  - "4000" #let the container use 4000 port, and not exposed to localhost
  - "6000" #let the container use 6000 port, and not exposed to localhost

1-2-8-3.If container,localhost use the same service on the same port, how to connect them?
To docker-compose.yml, add below parameters to service:
services:

  web:
    .....
    extra_hosts:
      - "host.docker.internal:host-gateway"
    .....

1-3.Docker Registry:
It's a repository for docker.Same as GitHub.
1-3-1.The learning resource:
Youtube Tutorial PART 4 - Docker push image to Docker Hub 教學

1-3-2.Registration:
Follow below resource to registry for the Docker Registry:
https://hub.docker.com/

1-3-3.Login to Docker Registry:
docker login

1-3-4.Commit the message to Docker Registry:
Step1.Run the busybox container:
docker run -it busybox
Step2.Then, add the data:
echo 'text' > data.txt
Step3.Open the another terminal,use 'docker ps' to check the container's id.

Step4.Commit the change to Docker Registry:(Very Important)
docker commit -m "test" {container_id} {defined repository_name}
--->test is the commit message
*If need tag,we can do below:
docker commit -m "test" {container_id} {defined repository_name:v1}
But if not tag,the system will tag 'latest' to repository_name automatically:
docker commit -m "test" {container_id} {defined repository_name:latest}

Step5.Push the change to Docker Registry:
docker push {defined repository_name}

Step6.After that,you can browse the Docker Registry Web to check whether change uploads successful or not?
The Docker Registry Web Resource:
https://hub.docker.com/
